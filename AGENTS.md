# Agent Instructions

This repository develops the reusable Agent Project Framework. The installable
payload lives under `skeleton/`.

The Manager/Implementer workflow under `skeleton/` applies to projects that
install the framework. It does not automatically govern work on this framework
repository.

When working on this repository, follow the user's explicit task and scope.
Do not infer a Manager or Implementer role unless the user explicitly chooses
to use that workflow for framework development.
